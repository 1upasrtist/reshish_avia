# Решись Авиа — Веб-сервис прогнозирования спроса и продаж авиабилетов 

**Автор проекта:** Морозов Арсений Игоревич  
**Файл данных прогноза:** `Morozov_Arseniy_Igorevich_my_forecast.csv`

## О проекте
Веб-приложение для менеджеров авиакомпании «Решись Авиа», позволяющее в реальном времени оценивать потенциальный спрос и ожидаемые продажи авиабилетов на выбранный рейс из Москвы (на период с 1 июня по 1 июля 2026 года) при заданной цене.

### Реализованный функционал
* **Backend API (Python / Flask):** загрузка и обработка данных ML-прогноза, расчёт линейного спроса с учётом коэффициента ценовой эластичности (`price_sensitivity`) и ограничение продаж вместимостью воздушного судна (`seats`).
* **Frontend-интерфейс (HTML5 / CSS3 / JavaScript):** форма выбора направления (`MOW-AER`, `MOW-LED`, `MOW-KGD`, `MOW-OVB`, `MOW-MRV`), даты вылета и цены билета с мгновенным обновлением показателей без перезагрузки страницы (`Fetch API`).
* **График распределения спроса (HTML5 Canvas):** визуализация потенциального спроса и фактических продаж по всем 9 квантилям прогноза (`0.1` — `0.9`) с отображением линии вместимости самолёта.
* **Регистрация и авторизация:** система учётных записей сотрудников с хэшированием паролей (`Werkzeug Security`), хранением пользователей в базе данных `SQLite` и управлением сессиями на сервере.
* **Размещение на хостинге:** приложение развёрнуто в облаке с использованием WSGI-сервера `Gunicorn`.

## Использованные модели и технологии ИИ
В соответствии с условиями задания при разработке продукта применялись технологии генеративного искусственного интеллекта:
* **Модель ИИ:** **Gemini** (большая языковая модель от Google).
* **Инструменты и задачи, решённые с помощью ИИ:**
  * проектирование клиент-серверной архитектуры приложения;
  * генерация и отладка кода backend-сервера на Python (`Flask`, `SQLite`, обработка CSV-данных);
  * верстка адаптивного веб-интерфейса (`HTML/CSS`) и написание клиентской логики на `JavaScript`;
  * реализация модуля графической отрисовки распределения спроса по квантилям на `HTML5 Canvas`;
  * настройка окружения и конфигурации для деплоя веб-сервиса на облачный хостинг (`Gunicorn`, `requirements.txt`).

## Локальный запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте в браузере адрес `http://127.0.0.1:5000`.
